# Claude game studio skills

Two skills for building games with Claude using an agent-team "studio" workflow.

| Skill | Use it when |
| --- | --- |
| `browser-game-studio/` | Designing, building, extending or playtesting a browser game published as a Claude Artifact. Covers the Director-led agent chain, cost rules, the design-first blueprint workflow, build rules and the smoke-test/ship loop. |
| `minecraft-mod-studio/` | The game is a Minecraft Java mod or modpack on NeoForge. Covers version pinning, project shape, naming conventions, total-conversion rules, content pipeline, testing and modpack shipping. Used together with `browser-game-studio`. |

## Install

Each folder is a standard skill: a `SKILL.md` with frontmatter (`name`, `description`) and instructions. Copy a folder into your skills directory, or upload the folder as a skill in Claude. The skills reference project docs (a studio playbook, per-game canon, DEVGUIDE, ROADMAP, PLAYTEST, CHANGELOG) that you create in your own project.
